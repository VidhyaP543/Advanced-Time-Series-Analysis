# Advanced-Time-Series-Analysis
Daily Temperature Forecasting Using Time Series Analysis (ARIMA)
Project Overview

This project demonstrates the application of Time Series Analysis to forecast daily minimum temperatures using historical weather data. The ARIMA (AutoRegressive Integrated Moving Average) model is used to analyze temporal patterns and predict future temperature values.

Objectives
Analyze historical temperature data.
Perform data preprocessing and exploratory data analysis.
Test the stationarity of the time series using the Augmented Dickey-Fuller (ADF) test.
Build an ARIMA forecasting model.
Predict future temperature values.
Evaluate the model using MAE and RMSE.
Dataset
Dataset Name: Daily Minimum Temperatures
Domain: Weather Forecasting
Time Period: 1981–1990
Number of Records: 3,650
Features: Date, Temperature
Technologies Used
Python
Jupyter Notebook
Pandas
NumPy
Matplotlib

Scikit-learn
Project Workflow
Load the dataset.
Preprocess the data.
Perform Exploratory Data Analysis (EDA).
Conduct the Augmented Dickey-Fuller (ADF) test.
Build the ARIMA model.
Forecast future temperatures.
Evaluate the model.
Visualize the results.
Results

The ARIMA model successfully analyzed historical temperature patterns and generated future temperature forecasts. The model's performance was evaluated using Mean Absolute Error (MAE) and Root Mean Squared Error (RMSE), demonstrating the effectiveness of time series forecasting for weather data.
